# 连续可变推力六自由度模型与仿真规格

版本：v0.2 设计规格。日期：2026-10-11。

用户目标：保留仓库已有三自由度内容，新增六自由度模型与仿真。继续使用虚构的小型民用试验飞行器参数，跑通动力输入、质量变化、气动力、三轴力矩、姿态与位置积分，输出实际计算得到的曲线。总体设计已经确认，本文给出正式模型约定和后续实现的验收标准。

本文是设计文档，新增六自由度程序的运行情况将在实现阶段的验证记录中说明。

## 1. 保留范围与新增范围

原 `c/`、`matlab/`、`results/`、`tests/` 以及原三自由度模型说明保留。新模型的源码、测试和结果进入 `six_dof/`；根目录运行说明增加六自由度入口，CMake 增加独立目标。

新增模型包含三轴平动、三轴刚体转动、四元数姿态、机体系气动力与力矩、连续推力响应以及耗油。攻角和侧滑角由速度计算；滚转、俯仰和偏航由角运动方程积分。

采用局部平直地面、恒定重力、零风、固定质心、固定对角转动惯量。推力沿机体前向并通过质心。参考面积、惯量和气动系数均是教学输入。质量变化是抽象耗油模型；本版忽略燃料变化引起的惯量和质心变化，不建立排出物的附加转动力矩。推力按净推进力使用。

## 2. 坐标、姿态和单位

内部地面坐标采用右手系 `n`：初始前向 N、初始右向 E、竖直向下 D。这是 NED 形式的局部坐标，不引入真实经纬度或地球自转。

机体系 `b` 同样是右手系：`x_b` 向前、`y_b` 向右、`z_b` 向下。机体系速度为 `v_b=[u,v,w]^T`，角速度为 `omega_b=[p_b,q_b,r_b]^T`。

轨迹输出采用原工程约定：

\[
x=N,\qquad y=-D,\qquad z=E.
\]

地面速度先计算 `v_n=R_nb v_b`，再输出 `v_x=V_N`、`v_y=-V_D`、`v_z=V_E`。航迹倾角为 `atan2(-V_D,hypot(V_N,V_E))`。图中使用的航迹方位角另记为 `psi_v=atan2(-V_E,V_N)`，与正向右的地面航向角符号相反。

四元数记为 `Q=[a,b,c,d]^T`，标量在前，采用 Hamilton 乘法；`R_nb(Q)` 明确定义为将机体系分量转为地面系分量的主动旋转矩阵。姿态欧拉角按 Z-Y-X 顺序输出，分别叫 `roll`、`pitch`、`yaw`，与航迹倾角分开命名。

全部状态与内部参数采用 SI 单位：位置 m、速度 m/s、力 N、力矩 N·m、质量 kg、惯量 kg·m²、时间 s、角度 rad、角速度 rad/s。PNG 中角度和舵偏转为度，并标明单位。

## 3. 十五维状态

\[
s=[N,E,D,u,v,w,a,b,c,d,p_b,q_b,r_b,m,T]^T.
\]

| C 数组下标 | MATLAB 下标 | 内容 |
|---|---|---|
| 0—2 | 1—3 | 地面系位置 N、E、D |
| 3—5 | 4—6 | 机体系速度 u、v、w |
| 6—9 | 7—10 | 四元数 a、b、c、d |
| 10—12 | 11—13 | 机体系角速度 p_b、q_b、r_b |
| 13 | 14 | 总质量 m |
| 14 | 15 | 实际推力 T |

六自由度表示三个平移和三个旋转自由度；四元数多出的一个分量由单位范数约束，质量和推力是附加动态状态。

## 4. 旋转矩阵与姿态运动学

对单位四元数：

\[
R_{nb}=\begin{bmatrix}
a^2+b^2-c^2-d^2&2(bc-ad)&2(bd+ac)\\
2(bc+ad)&a^2-b^2+c^2-d^2&2(cd-ab)\\
2(bd-ac)&2(cd+ab)&a^2-b^2-c^2+d^2
\end{bmatrix}.
\]

姿态积分为：

\[
\dot Q=\frac12Q\otimes[0,\omega_b]^T
=\frac12\begin{bmatrix}
0&-p_b&-q_b&-r_b\\
p_b&0&r_b&-q_b\\
q_b&-r_b&0&p_b\\
r_b&q_b&-p_b&0
\end{bmatrix}Q.
\]

每个已接受的积分步归一化四元数。RK4 阶段计算旋转矩阵时使用归一化副本，阶段四元数导数仍按上式计算。范数非有限或小于 `1e-12` 时报告计算失败。

输出欧拉角：

\[
\phi=\operatorname{atan2}(2(ab+cd),1-2(b^2+c^2)),
\]
\[
\vartheta=\arcsin(\operatorname{clip}(2(ac-db),-1,1)),
\]
\[
\psi=\operatorname{atan2}(2(ad+bc),1-2(c^2+d^2)).
\]

欧拉角采用主值。接近俯仰 ±90° 时滚转与偏航的分解不唯一，积分与姿态核对使用四元数及旋转矩阵。四元数 `Q` 与 `-Q` 表示同一姿态。

## 5. 平动与刚体转动方程

定义 `g_n=[0,0,g]^T`、净推力 `F_T,b=[T,0,0]^T`，气动力为 `F_A,b`，关于质心的气动力矩为 `M_A,b`：

\[
\dot r_n=R_{nb}v_b,
\]
\[
\dot v_b=\frac{F_{A,b}+F_{T,b}}{m}
+R_{nb}^Tg_n-\omega_b\times v_b,
\]
\[
J\dot\omega_b+\omega_b\times(J\omega_b)=M_{A,b}.
\]

机体系速度方程中的交叉乘积来自坐标轴转动。它不等于额外气动力；重力只在 `R_nb^T g_n` 中加入一次。

对于 `J=diag(J_x,J_y,J_z)`，角速度方程展开为：

\[
\dot p_b=[M_x+(J_y-J_z)q_br_b]/J_x,
\]
\[
\dot q_b=[M_y+(J_z-J_x)p_br_b]/J_y,
\]
\[
\dot r_b=[M_z+(J_x-J_y)p_bq_b]/J_z.
\]

固定惯量和固定质心是本版明确的简化。若未来引入随燃料变化的惯量，需一起重新定义惯量变化和质量流动的角动量平衡，不能只替换一个 J 数值。

## 6. 气动力方向与攻角、侧滑角

零风时相对空气的机体系速度就是 `v_b`：

\[
V=\sqrt{u^2+v^2+w^2},\quad
\alpha=\operatorname{atan2}(w,u),\quad
\beta=\operatorname{atan2}(v,\sqrt{u^2+w^2}).
\]

高度 `h=-D`，密度 `rho=rho0*exp(-max(h,0)/H)`，动压记为 `q_dyn=0.5*rho*V²`。

定义机体系中的风轴基向量：

\[
e_{xw}=[\cos\alpha\cos\beta,\sin\beta,\sin\alpha\cos\beta]^T,
\]
\[
e_{zw}=[-\sin\alpha,0,\cos\alpha]^T,
\]
\[
e_{yw}=e_{zw}\times e_{xw}
=[-\cos\alpha\sin\beta,\cos\beta,-\sin\alpha\sin\beta]^T.
\]

三个向量构成右手正交基。阻力沿负风轴前向，升力沿负风轴下向，正侧向力沿风轴右向：

\[
F_{A,b}=-D_Ae_{xw}+Y_Ae_{yw}-L_Ae_{zw}.
\]

其中 `D_A` 是阻力大小，与位置状态 D 区分。如此构造使升力、侧向力与相对空气速度正交，阻力做功为 `-D_A V`。

## 7. 虚构气动系数与力矩

\[
C_L=\operatorname{clip}(C_{L0}+C_{L\alpha}\alpha,-0.6,1.2),\quad
C_D=C_{D0}+kC_L^2,
\]
\[
C_Y=C_{Y\beta}\beta+C_{Y\delta_r}\delta_r,
\quad (L_A,D_A,Y_A)=q_{dyn}S(C_L,C_D,C_Y).
\]

无量纲角速度取：

\[
\hat p=p_bb_{ref}/(2V_{safe}),\quad
\hat q=q_bc_{ref}/(2V_{safe}),\quad
\hat r=r_bb_{ref}/(2V_{safe}),
\]

其中 `V_safe=max(V,1e-3 m/s)`。力矩系数为：

\[
C_l=C_{l\beta}\beta+C_{lp}\hat p+C_{lr}\hat r+C_{l\delta_a}\delta_a,
\]
\[
C_m=C_{m0}+C_{m\alpha}\alpha+C_{mq}\hat q+C_{m\delta_e}\delta_e,
\]
\[
C_n=C_{n\beta}\beta+C_{np}\hat p+C_{nr}\hat r+C_{n\delta_r}\delta_r,
\]
\[
M_{A,b}=q_{dyn}S[b_{ref}C_l,c_{ref}C_m,b_{ref}C_n]^T.
\]

`delta_a`、`delta_e`、`delta_r` 是示例副翼、升降舵和方向舵输入，单位 rad。其正负通过上述系数定义：正副翼产生正滚转力矩，正升降舵产生负俯仰力矩，正方向舵产生负偏航力矩。

| 系数 | 值 | 系数 | 值 |
|---|---:|---|---:|
| C_L0 | 0.2 | C_Lalpha | 4.5 /rad |
| C_D0 | 0.035 | k | 0.06 |
| C_Ybeta | -0.5 /rad | C_Ydelta_r | 0.12 /rad |
| C_lbeta | -0.08 /rad | C_lp | -0.45 |
| C_lr | 0.10 | C_ldelta_a | 0.12 /rad |
| C_m0 | 0.03 | C_malpha | -0.80 /rad |
| C_mq | -5.0 | C_mdelta_e | -1.0 /rad |
| C_nbeta | 0.08 /rad | C_np | -0.04 |
| C_nr | -0.20 | C_ndelta_r | -0.08 /rad |

当 `V<1e-8 m/s` 时观测攻角和侧滑角记为零，气动力和气动力矩置零，保留重力与沿真实姿态机体轴线的推力。系数与升力截断只定义教学替代模型；未建立真实失速或大攻角气动。

## 8. 连续可变推力与质量变化

\[
T_{cmd}=T_{max}\operatorname{clip}(\eta(t),0,1),\quad
\dot T=(T_{cmd}-T)/\tau_T,
\]
\[
\dot m=-(c_0+c_TT).
\]

消耗率使用实际推力。发动机开启条件为有剩余燃料；基础消耗 `c0` 在开启期间存在，即使油门暂为零。关闭耗油的解析测试可保持发动机开启而质量固定。

到达干质量时定位事件，令 `m=m_dry`、`T=0`，之后 `T_dot=0`、`m_dot=0`，并继续无动力运动。推进净力按给定 T 加入，不重复加入相同推进过程的动量项。

## 9. 默认参数、完整初始配平与输入

| 参数 | 值 |
|---|---:|
| 初始质量 / 干质量 | 12 / 11.7 kg |
| 初速 / 初始高度 | 25 m/s / 200 m |
| 参考面积 S | 0.8 m² |
| 参考翼展 b_ref / 弦长 c_ref | 2.0 / 0.4 m |
| J_x / J_y / J_z | 1.0 / 1.6 / 2.2 kg·m² |
| g / rho0 / H | 9.80665 m/s² / 1.225 kg/m³ / 8500 m |
| 最大推力 / 响应时间常数 | 60 N / 1 s |
| c0 / cT | 5e-5 kg/s / 1.5e-5 kg/(N·s) |
| 仿真上限 / 积分步长 | 120 s / 0.01 s |
| 默认 CSV 输出间隔 | 每 5 个已接受的常规积分步，并记录初态与末态 |

六自由度基准油门取自身的完整水平稳态配平结果。初始角速度和侧滑为零，副翼与方向舵为零，升降舵由零俯仰力矩条件求得。

求解：

\[
L_A(\alpha_0)+D_A(\alpha_0)\tan\alpha_0=m_0g,
\quad T_0=D_A(\alpha_0)/\cos\alpha_0,
\]
\[
\delta_{e0}=-(C_{m0}+C_{m\alpha}\alpha_0)/C_{m\delta_e},\quad
\eta_0=T_0/T_{max}.
\]

在 ±15° 范围内采用有界求根。无根、`cos(alpha0)` 过小或 `T0` 超出允许范围时明确报告配平失败。配平要求初始机体系速度导数和角速度导数各分量绝对值小于 `1e-8`，位置导数不为零。

初态：`r_n=[0,0,-h0]`、`v_b=[V0*cos(alpha0),0,V0*sin(alpha0)]`、`Q=[cos(alpha0/2),0,sin(alpha0/2),0]`，`omega_b=0`、`m=m0`、`T=T0`。这样初始地面速度为 `[V0,0,0]`。

恒定指令案例采用 `eta(t)=eta0`。变推力案例采用：

\[
\eta(t)=\eta_0+0.15\sin(2\pi t/40)+0.05\sin(2\pi t/15).
\]

两例的初态、参数和舵面输入一致。对比的“恒定”指油门指令恒定，不保证状态变化或燃料耗尽时的实际推力恒定。

为了观察三轴姿态响应，两例施加相同小幅开环舵面输入。定义平滑窗口 `W(t;t1,t2)=sin²(pi*(t-t1)/(t2-t1))`，窗口外为零：

\[
\delta_a(t)=0.2^\circ W(t;20,40)\sin[2\pi(t-20)/8],
\]
\[
\delta_e(t)=\delta_{e0},\qquad
\delta_r(t)=0.1^\circ W(t;45,65)\sin[2\pi(t-45)/10].
\]

角度幅值在进入方程前转为 rad。窗口边界的一阶导数连续；输入不依赖仿真状态。零舵面扰动的配平测试与上述默认演示分开设置。

## 10. 积分、事件与错误处理

使用固定步长 RK4，同时积分全部十五项状态。最后一步缩短以到达指定上限时刻。

燃料耗尽发生在步内时，通过二分定位，分成开启和关闭两个子步；同一 RK4 子步的四个阶段使用相同发动机状态。触地事件以 `h=-D=0` 定位并停止；二分探测调用完整的推进事件处理，支持同一步内耗尽并触地。

每个接受状态检查有限性、四元数范数、质量和推力边界。已接受状态的质量不低于干质量，推力处于 `[0,Tmax]`。触地末态高度精确记为零。

模式、时长、步长及输出路径在命令行入口检查：数值必须有限，时长和步长必须为正，模式必须已定义，文件必须成功打开。任何失败返回非零退出码。任意正仿真时长应记录初态与末态，不因时长很小而只输出初态。

## 12. 输出契约

CSV 至少包含：`t_s`；原坐标形式的位置与速度；机体系 `u_mps,v_mps,w_mps`；`quat_a,quat_b,quat_c,quat_d`；`p_radps,q_radps,r_radps`；`roll_rad,pitch_rad,yaw_rad`；`alpha_rad,beta_rad`；航迹倾角与 `psi_v_rad`；`mass_kg,thrust_N,thrust_cmd_N,throttle`；三项舵偏；升力、阻力、侧向力和三轴力矩；四元数范数误差。

列名写入表头；角度列一律存 rad。若使用输出抽样，计算仍保持原积分步长，事件末态总是单独记录，时间严格递增。

默认交付图像：

1. 三维轨迹及前向距离—高度图，坐标按 x 前、y 上、z 右。
2. 滚转、俯仰、偏航与三轴角速度随时间的曲线。
3. 攻角、侧滑角、指令/实际推力、质量与舵面输入随时间的曲线。

恒定指令和变推力结果在相同坐标轴上比较。摘要记录所有默认参数、配平值、步长、输出抽样、最终时刻、终止原因、末态和主要范围，图像由 CSV 数据生成。

## 13. 验收标准

| 验证项目 | 独立判据 |
|---|---|
| 坐标与符号 | 单位姿态 R 为单位阵；正 90° 偏航将机体前向转为 E；正滚转与升力侧向分量方向一致；R 正交且行列式为 +1 |
| 自由落体 | 关闭气动、推力和耗油，在多种固定姿态下，转换后的地面位置与速度符合解析抛物运动 |
| 恒定角速度 | 球形惯量、零力矩、关闭外力，四元数与解析轴角旋转一致；旋转不能凭空改变惯性系速度 |
| 非球形无外矩转动 | 关闭气动力矩，旋转动能和惯性系角动量在数值误差内守恒，减半步长改善误差 |
| 推力响应 | 关闭耗油与其他外力，固定姿态，实际推力与一阶阶跃解析解一致 |
| 初始配平 | 无扰动、初始状态的三个速度导数和三个角速度导数各小于 1e-8；冻结质量后短时平直飞行保持配平 |
| 气动力做功 | 升力及侧向力对空速的点积为零；阻力点积为 -D_A V；允许量级相关的浮点误差 |
| 燃料耗尽与触地 | 采用解析可核对案例，质量不越界、耗尽后无推力、末态高度为零；事件时刻在减半步长时收敛 |
| 四元数与有限性 | 默认完整两例全部状态有限，每个接受状态单位范数误差不超过 1e-12 |
| 步长收敛 | 默认 dt=0.01 与 0.005 在共同采样时刻比较，最大位置差小于 0.05 m，速度差小于 0.01 m/s，姿态旋转差小于 0.05°；若有事件，另比较事件时刻 |
| 案例差异 | 两例均生成有效结果；变推力指令、实际推力和至少一项轨迹量与恒定指令案例不同 |
| 原三自由度回归 | 原源码、原结果数据与图片的内容哈希保持；原物理检查仍通过 |

解析测试采用 double 精度；其容差需结合解析量级和积分时长在测试记录中给出。阈值只衡量实现与本教学方程的一致性，不衡量真实飞行器预测精度。

实现完成时才记录实际测试结果、图片和运行摘要。当前文档不预先填报任何六自由度测试通过。

## 14. 参考与约定说明

刚体机体系运动方程及四元数运动学参考以下一手资料：

- MathWorks：[6DOF (Euler Angles)](https://www.mathworks.com/help/aeroblks/6dofeulerangles.html)。
- MathWorks：[6DOF (Quaternion)](https://www.mathworks.com/help/aeroblks/6dofquaternion.html)。

本工程独立编写方程与积分器。本文的 `R_nb` 明确是机体到地面的变换；参考页面中的坐标变换方向应逐项核对，不能仅凭四元数名称推断矩阵方向。虚构气动、惯量、耗油参数和演示输入由本文定义，并非来自上述资料的真实机型数据库。
