# 固体助推起飞与巡航接管教学情形

## 目标与范围

按用户新增情形请求，在现有六自由度教学工程中增加从静止释放、固体助推爬升、满足高度及速度条件后点燃持续巡航动力的完整仿真。使用虚构的小型固定翼试验飞行器参数；保留已有三自由度及六自由度两案例。C 实际编译运行，MATLAB 独立源码与 C CSV 绘图入口同步提供，执行局限据实记录。

## 复用与状态

复用 `six_dof/c/six_dof.c` 的右手机体/NED 刚体方程、气动力、四元数及观察量，不更改其接口或默认参数。新增独立 `six_dof/boost_cruise/`。连续状态为原 15 维状态加助推剩余推进剂、巡航剩余燃料，共 17 个数；原推力状态 T 专指巡航实际推力。质量始终满足 `m = dry_mass + boost_fuel + cruise_fuel`。离散状态记录助推燃烧、巡航已点火、巡航燃料耗尽、已离地及点火时间。

惯量、重心固定；助推壳体一直保留，不模拟抛离。两种动力沿机体前轴且穿过重心。零风、平地、恒定重力及虚构气动假设沿用原模型。零速没有气动力，推力及重力仍按姿态计算。

## 固体助推与巡航动力

助推器采用一次点火的预设平顶净推力曲线，燃烧区间 `[0,t_b)` 内为 `T_b`，区间外为零。推进剂质量流量为 `boost_fuel0/t_b`。这是抽象的净推力/流量输入，不涉及燃烧室、药柱或真实发动机设计；发动机净推力不重复计入排气反作用。

助推器只在自然燃尽时关闭。巡航点火条件为 `h >= ignition_height AND V >= ignition_speed`；用子步内二分定位第一次满足条件的时刻，点火锁存，不因后续暂时低于门限反复开关。若门限先达到，助推与巡航可重叠；若助推先燃尽，进入无动力滑行并继续监测门限，未达到则不伪造成功接管。

巡航动力沿用最大 60 N、一阶响应时间常数 1 s、基于实际推力的抽象耗油模型；点火时巡航实际推力仍为零，其后连续建立。点火后指令最低为虚构的 3 N 怠速推力，使助推造成超速时仍有巡航动力连续建立。巡航燃料耗尽时定位事件并置实际推力为零。助推燃尽及巡航点火不重置位置、速度、角速度或四元数。

## 起飞与简易稳定控制

默认在地面高度 0 m、速度 0 m/s、初始俯仰 35°时释放；助推从首个时刻给出设定净推力。要求初始竖直加速度向上，否则报告无法在本释放模型下离地。本情形不建轮胎、导轨或接地反力模型；触地事件只在离地后启用。

虚构默认：干质量 11.7 kg，助推推进剂 0.5 kg，巡航燃料 0.3 kg，总质量 12.5 kg；助推推力 260 N、燃烧 4 s；点火门限高度 40 m、速度 25 m/s；巡航高度目标 40 m、速度目标 25 m/s；时长 120 s、步长 0.005 s、每 10 个常规步输出。

助推段保持初始俯仰指令。巡航点火后，以 3 s 三次平滑插值把俯仰指令过渡至 `alpha_trim + gamma_cmd`，`gamma_cmd = clip(0.02*(h_ref-h), +/-8 deg)`。升降舵使用气动俯仰项补偿及俯仰/角速度反馈：`de = clip(-(Cm0+Cm_alpha*alpha)/Cm_e + 0.8*(pitch-pitch_cmd) + 0.25*q, +/-20 deg)`。无副翼/方向舵输入，因此默认为对称平面轨迹，但积分全部六自由度。

巡航净推力指令使用阻力/爬升补偿及速度比例反馈：`T_cmd = clip((drag + m*g*sin(gamma_cmd))/max(cos(alpha),0.8) + 5*(V_ref-V), 3, 60)`。原初始配平函数仅用于求取参考巡航迎角，不用于覆盖当前飞行状态。这是基础教学稳定器，不代表真实飞控设计或性能验证。

## 积分、事件与输出

使用 17 维 RK4；每个子步的助推/巡航启停标志固定，避免在 RK4 中途提前改变模式。单次推进返回最早事件及实际推进时长，由调用者积分剩余时间；依次处理点火、固体燃尽、巡航燃料耗尽、触地，包括同一常规步内的多个事件。触地优先终止。常规输出时间和事件输出时间均保存；相同时间合并，避免重复时间行。

CSV 扩展原字段，增加助推推力、巡航/总推力、两类剩余燃料、质量流量、门限状态、阶段编号、点火锁存、稳定器指令。CSV 角度为 rad，图中为 deg。输出轨迹、高度/速度门限、动力交接、燃料、俯仰/航迹角和阶段曲线；摘要含实际事件时刻、参数、终止原因及步长减半误差。

## 验证要求

解析验证无气动/无重力下助推速度和门限时刻；分别验证只满足一个门限不会点火、点火后锁存、点火时巡航推力不跳变、固体燃尽精确定位及不受巡航油门控制、未满足门限的滑行、巡航燃料耗尽和触地。无效参数、极短正时长及事件/常规输出时序应有检查。默认与半步长的公共网格最大位置误差 <0.05 m、速度 <0.01 m/s、姿态 <0.05°，四元数范数误差 <=1e-12。原六自由度解析/输出及三自由度回归均须保持通过。最终独立审查后通过 GitHub 连接器增量提交并核对远端哈希。
