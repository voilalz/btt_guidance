# 六自由度仿真实际验证记录

执行日期：2026-10-11。验证使用 GCC、C99、double 精度，开启 `-O2 -Wall -Wextra -Werror`。当前环境没有 MATLAB、Octave 或 CMake，因此没有声明这三条运行路径已执行；MATLAB 方程及参数采用独立源码实现，曲线来自实际执行的 C 程序。

## 1. 解析及边界检查

执行 `python six_dof/tests/run_checks.py all`，下列检查全部通过。

| 检查 | 解析基准及容差 |
|---|---|
| 旋转矩阵 | 恒等矩阵、正偏航转向右、正滚转升力向右，正交性及 det=+1，误差 <1e-14；零/非有限四元数返回失败 |
| 完整初始配平 | 三个速度导数及三个角速度导数各 <1e-8；独立求得的迎角误差 <1e-12 rad，推力误差 <1e-9 N |
| 定质量配平飞行 | 禁用扰动及耗油，10 s 水平飞行；位置误差 <1e-8 m |
| 气动力功率 | 非零迎角/侧滑角下 \(\mathbf F_a\cdot\mathbf v=-D_aV\)，残差 <1e-9 W；零速气动力/力矩为零 |
| 多姿态自由落体 | 2 s，步长 0.01 s；惯性位置误差 <1e-9 m，惯性速度误差 <1e-10 m/s |
| 球形无力矩刚体 | 5 s，角速度为 (0.2,-0.3,0.4) rad/s；四元数解析误差 <1e-11，旋转机体系下惯性速度/位置残差 <1e-8 |
| 非球形无力矩刚体 | 20 s，惯量 (1,1.6,2.2)；检查旋转能量及惯性角动量守恒，步长 0.02→0.01 s 的测试合成残差 1.26e-8→7.89e-10，约按四阶缩小 |
| 实际推力一阶响应 | 5 s，\(T(t)=36+(2-36)e^{-t}\)，误差 <1e-9 N |
| 燃料耗尽 | 定推力、定质量流量；干质量与关机状态精确设置，耗尽前速度解析误差 <1e-8 m/s |
| 触地时刻 | 10 m 自由落体，与 \(\sqrt{20/g}\) 比较，时间误差 <2e-10 s，触地速度误差 <2e-9 m/s |
| 同一步两个事件 | 一个 2 s 步长内先耗尽燃料后触地，与 0.01 s 结果比较；时间误差 <2e-10 s |
| 无效状态与 CLI | 零步长、非有限状态、低于干质量、非法模式、nan/inf/负数/尾随字符/零输出间隔/文件打开失败均返回错误 |
| 非有限模型参数 | NaN 气动系数/限幅边界/油门覆盖输入、非有限配平舵角，以及有限参数导致配平输出溢出均返回失败；不会被限幅函数掩盖 |
| 输出时序 | 极短正时长 1e-12 s 仍有初始及末样本；0.123 s 末步缩短并输出，时间严格递增；坐标互换检查通过 |

非球形刚体测试中的“合成残差”将能量残差数值与三个角动量残差绝对值相加，只用于该固定算例的数值收敛判断，不作为统一物理单位的性能指标。全部容差用于验证教学方程的实现，并不代表真实飞行器预测误差。

## 3. 步长减半

同一模型分别使用 0.01 s（每 5 步输出）与 0.005 s（每 10 步输出），在 2401 个公共 0.05 s 网格样本上比较；不插值姿态。姿态误差通过两个单位四元数的相对旋转角计算，处理了 Q 与 -Q 的等价性。

| 最大差异 | 恒定油门 | 可变油门 | 验收阈值 |
|---|---:|---:|---:|
| 位置向量范数 | 1.36e-9 m | 2.45e-9 m | 0.05 m |
| 速度向量范数 | 2.25e-11 m/s | 8.33e-11 m/s | 0.01 m/s |
| 姿态角 | 9.88e-10° | 1.08e-9° | 0.05° |

这些差异衡量同一数值模型的积分稳定性。六自由度案例未另用高精度独立求解器对照；解析刚体/力学检查与步长收敛共同作为当前验证依据。
