# 连续可变推力轨迹教学模型

目的：以虚构的小型民用试验飞行器参数，跑通推力指令、推力响应、燃料消耗、升阻力、重力、RK4积分、CSV输出与轨迹绘图流程。

范围：三维质点模型，状态 [x,y,z,vx,vy,vz,m,T]；x前、y上、z右；零风、局部平直地面；姿态不积分，攻角与倾侧角由光滑时间函数给定，侧滑为零。此模型不预测真实飞行器性能。

参数：初始质量12 kg、干质量11.7 kg、参考面积0.8 m²、初速25 m/s、初始高度200 m、最大推力60 N、响应时间常数1 s、时长120 s、步长0.02 s。升力与阻力系数为虚构参数。

对比：相同初态、气动、攻角与倾侧角，分别输入恒定推力指令和连续变推力指令。两种指令平均油门相同；初始实际推力也相同，推力响应与最终燃料消耗不强求相同。

输出：中文注释的C99核心与命令行程序；独立MATLAB函数，运行时直接生成轨迹与状态图；CSV、PNG、说明。MATLAB不依赖专用工具箱。本环境只有GCC，MATLAB运行验证不得虚报。

数值边界：燃料耗尽时通过步内二分定位事件，质量保持干质量，关闭实际推力，再积分余下时间。地面事件二分定位并终止；低速和近竖直飞行时采用明示的法向基向量降级，不声称解析真实起飞姿态。

验收：真空自由落体与解析解吻合；一阶推力响应与解析解吻合；无阻力无推力时升力不做功；燃料不为负且耗尽后无推力；减半步长结果收敛；默认两组案例输出不同且全部有限的轨迹。
