# 验证记录

日期：2026-10-11。运行环境：Linux/GCC，C99；独立积分工具为SciPy DOP853。

## 实际完成的验证

1. GCC使用 `-std=c99 -O2 -Wall -Wextra -Werror` 成功编译核心与命令行程序，无警告。
2. 六个物理/数值边界算例通过：
   - 真空自由落体的三维位置与速度符合解析解；
   - 固定指令的一阶推力响应符合指数解析解；
   - 无推力、无阻力、恒质量时，升力不改变机械能；
   - 跨步燃料耗尽后质量等于干质量，推力和耗油率为零；
   - 零速与竖直速度的方向降级不产生NaN/Inf；
   - 触地时间符合独立解析根，最后高度为零。
3. 默认恒定/可变两组案例均完成120 s，共6001行数据；所有状态有限，质量单调且不低于干质量，推力有界。
4. 两组推力指令在120 s内的平均值均为12 N。
5. C的RK4结果与独立建立的矢量方程、SciPy DOP853积分对照。两案例末位置最大分量差均小于1×10⁻⁸ m。
6. 用0.2、0.1、0.05、0.02、0.01 s步长重复积分。0.02 s与0.01 s的末位置最大分量差小于2×10⁻⁹ m；这表明默认平滑示例中积分误差很小，不表示真实物理精度达到纳米级。
7. 非法模式、零步长、负步长、NaN步长、零时长、无限时长均被命令行程序拒绝。
8. 对二维/三维图进行视觉检查；图中三维绘制顺序为x,z,y，竖直轴尺度放大并注明。
9. 最终独立代码复核未发现阻断交付的问题。修正极短正时长被固定绝对容差跳过的边界行为；1×10⁻¹¹ s单步算例实际执行并输出初始/末时刻两行。MATLAB相同容差表达式也已修改，但仍未运行。

精确数值在 `results/verification.json`。微小积分差不应理解为模型或气动参数的真实性；本例参数是虚构的。
