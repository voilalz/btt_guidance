# 连续可变动力飞行器的轨迹数学模型（教学版 v0.1）

本工程使用虚构的小型民用试验飞行器参数，验证从动力输入到轨迹输出的计算流程。程序实际积分运动方程，曲线不是预先画好的形状。它不用于估计真实飞行器的性能。

## 1. 如何理解上传图片中的方程

图片包含速度/航迹角动力学、刚体角运动、位置与姿态运动学，以及质量变化方程。这种结构并不专属于固体动力飞行器。推进形式主要通过推力、消耗率和质量属性进入方程。

符号需要区分：

| 图片符号 | 含义 | 本程序处理 |
|---|---|---|
| P | 推力，单位N，不是功率 | 用T表示，作为动态状态 |
| X、Y、Z | 气动力分量 | 用阻力D与升力L，侧滑为零 |
| θ | 航迹倾角 | 由速度矢量计算 |
| ψ_v | 航迹方位角 | 保留图中dz/dt的负号约定 |
| ϑ、ψ、γ | 姿态俯仰、偏航、滚转角 | 本版不积分姿态 |
| γ_v | 速度系倾侧角 | 本版用μ表示，并给定时间函数 |
| α、β | 攻角、侧滑角 | 给定α(t)，假设β=0 |
| m_c | 质量消耗率 | 用实际推力决定的q_f表示 |

因此第一步是保持运动学与受力结构，补充“指令→实际推力→消耗率”的模型。仅把P替换为任意时间函数，而保持不相关的固定消耗率，会使动力与质量变化脱节。

## 2. 动力可变并不等于一种发动机

### 2.1 本工程的动力抽象

油门指令满足0≤δ≤1，使用示例静态映射：

\[
T_{cmd}=T_{max}\delta(t),\qquad
\dot T=\frac{T_{cmd}-T}{\tau_T}.
\]

这条一阶方程描述实际推力跟随指令的滞后。τ_T越小，跟随越快。它不是燃烧室、泵、螺旋桨或电机的详细模型；也没有额外实现硬性推力变化率限制。

本版的燃料模型为：

\[
q_f=c_0+c_T T,\qquad \dot m=-q_f.
\]

c_0表示发动机开启时的示例基础消耗，c_T的单位为kg/(N·s)。发动机消耗率使用实际推力T，而非尚未实现的指令推力T_cmd。

在m到达干质量m_dry的时刻，本版做理想熄火：m=m_dry、T=0、q_f=0，然后继续无动力积分。该瞬时熄火是教学假设，不表示真实发动机尾段过程。

### 2.2 更换动力类型时要更换什么

| 动力类型 | 所需动力/消耗关系 | 不能混淆的量 |
|---|---|---|
| 自带全部推进剂的发动机 | T=g_0 I_sp q_prop，m_dot=-q_prop | q_prop为全部推进剂消耗率 |
| 吸气式燃油动力 | T=f(油门、高度、速度)，m_dot=-q_f | 飞行器失去的是燃油；空气流量不是机载质量损失 |
| 电池电动动力 | T=f(电功率、速度、密度)，E_dot=-P_el，m近似不变 | 电能减少不等于飞行器质量按耗油规律减少 |

比冲关系来自比冲的定义，仅可在对应推进剂/燃料流量定义下使用。不能把所有推进系统统一套用同一个数值比冲。本工程没有实现具体发动机或功率到推力的模型。

如果“动力可变”指的是功率变化，还需要建立功率到推力的映射：功率单位W，推力单位N，二者不能直接互换。

## 3. 为什么本版选择三自由度

要验证动力变化如何改变轨迹，先积分质点平动即可。完整六自由度还需要惯量、质心、力矩、舵面和姿态控制等数据，当前示例没有这些输入。

采用局部固定地面坐标：+x是初始前向，+y竖直向上，+z初始右向。飞行后坐标轴不随飞行器旋转。采用平直地面、恒定重力、无风假设。

八维积分状态为：

\[
\mathbf s=[x,y,z,v_x,v_y,v_z,m,T]^T.
\]

这是三自由度平动加质量与推进状态，不是八个空间自由度。

不直接积分V、θ、ψ_v，原因是角形式包含1/V和1/cosθ。笛卡尔形式避免这些除法；方向基在低速/近竖直时仍须单独处理。

## 4. 气动力替代模型

本版用指数密度模型和简单升阻力系数：

\[
\rho(y)=\rho_0\exp[-\max(y,0)/H_\rho],\qquad
q=\frac12\rho V^2,
\]
\[
C_L=\operatorname{clip}(C_{L0}+C_{L\alpha}\alpha,C_{L,min},C_{L,max}),
\quad C_D=C_{D0}+kC_L^2,
\]
\[
L=qSC_L,\qquad D=qSC_D.
\]

升阻力的基本表达式是常用气动力定义。这里的系数数值和指数密度尺度均为教学输入；C_L截断只是数值替代，未建立真实失速、跨声速或高速气动模型。无风时空速等于地速。

## 5. 三维矢量运动方程

定义速度单位向量：

\[
V=\|\mathbf v\|,\qquad \mathbf e_v=\mathbf v/V.
\]

把固定竖直方向e_y=[0,1,0]^T投影到与速度正交的平面：

\[
\mathbf e_u=\frac{\mathbf e_y-(\mathbf e_y^T\mathbf e_v)\mathbf e_v}
{\|\mathbf e_y-(\mathbf e_y^T\mathbf e_v)\mathbf e_v\|},\qquad
\mathbf e_s=\mathbf e_v\times\mathbf e_u.
\]

倾侧角μ使升力法向为：

\[
\mathbf e_n=\cos\mu\,\mathbf e_u+\sin\mu\,\mathbf e_s.
\]

因此，正μ在初始水平前飞时会产生+z方向分量。零侧滑条件下，假设推力沿给定攻角对应的轴线：

\[
\mathbf F_T=T(\cos\alpha\,\mathbf e_v+\sin\alpha\,\mathbf e_n),\qquad
\mathbf F_A=-D\mathbf e_v+L\mathbf e_n.
\]

最终积分：

\[
\boxed{\dot{\mathbf r}=\mathbf v}
\]
\[
\boxed{\dot{\mathbf v}=
\frac{(T\cos\alpha-D)\mathbf e_v+(T\sin\alpha+L)\mathbf e_n}{m}
+[0,-g,0]^T}
\]
\[
\boxed{\dot m=-q_f,\qquad \dot T=(T_{cmd}-T)/\tau_T}.
\]

T在这里是发动机净推力，已包括对应动力模型中的动量交换；不能再额外添加一次同一排气动量项。

近竖直速度时，竖直方向投影接近零，程序改用固定x轴作参考。速度接近零时，程序临时用+x作推力/法向参考。这些处理保证数学量有限，并不能替代真实姿态和起飞动力学。

## 6. 与图片中的角形式对应

由笛卡尔速度计算：

\[
\theta=\operatorname{atan2}(v_y,\sqrt{v_x^2+v_z^2}),\qquad
\psi_v=\operatorname{atan2}(-v_z,v_x).
\]

在V>0、cosθ不接近零、β=0且无侧向气动力时，上述矢量方程等价于：

\[
m\dot V=T\cos\alpha-D-mg\sin\theta,
\]
\[
mV\dot\theta=(T\sin\alpha+L)\cos\mu-mg\cos\theta,
\]
\[
-mV\cos\theta\,\dot\psi_v=(T\sin\alpha+L)\sin\mu.
\]

位置方程保持原图的符号：

\[
\dot x=V\cos\theta\cos\psi_v,\quad
\dot y=V\sin\theta,\quad
\dot z=-V\cos\theta\sin\psi_v.
\]

原图的姿态运动学和角速度方程没有包含在本版积分中。攻角α和倾侧角μ由时间函数给定，因而这是理想姿态输入的质点仿真，不能推断真实飞行器能否跟随这些角度。

## 7. 两个示例案例

主要参数：

| 参数 | 示例值 |
|---|---:|
| 初始质量/干质量 | 12 / 11.7 kg |
| 初始速度/高度 | 25 m/s / 200 m |
| 参考面积 | 0.8 m² |
| 最大推力/响应时间常数 | 60 N / 1 s |
| C_L0 / C_Lα | 0.2 / 4.5 rad⁻¹ |
| C_D0 / k | 0.035 / 0.06 |
| c_0 / c_T | 5×10⁻⁵ kg/s / 1.5×10⁻⁵ kg/(N·s) |
| 积分步长/时长 | 0.02 s / 120 s |

恒定指令：δ=0.2，即T_cmd=12 N。

连续变指令：

\[
\delta(t)=0.2+0.15\sin(2\pi t/40)+0.05\sin(2\pi t/15).
\]

两种情况采用同样的攻角和倾侧角：

\[
\alpha(t)=\alpha_0+0.25^{\circ}\sin(2\pi t/30),\qquad
\mu(t)=8^{\circ}\sin(2\pi t/60).
\]

α_0只用于平衡初始竖直力：q_0SC_L(α_0)+12sinα_0=m_0g。这不是完整配平，攻角变化也不是自动驾驶控制器的输出。

120 s内两个指令的平均推力均为12 N，但由于响应滞后，实际推力积分及燃料消耗不严格相等。因此这只是相同平均指令的对照，不能解读为证明某种动力方案更优。

## 8. 数值积分和终止条件

程序使用经典四阶Runge–Kutta。在一个步长内的四个中间时刻分别计算动力输入、气动力和质量导数，不把所有输入冻结在步长起点。

燃料耗尽时，先保持发动机开启建立该步的试积分，再用45次二分定位m=m_dry；在该时刻关机，积分剩余步长。不会只把负燃料改为零而保留之后的推力。

位置跨越y=0时，同样在步内二分定位触地时刻，输出最后一行y=0并终止。否则到120 s终止。

对于修改后的参数，至少保持：m_0≥m_dry>0，τ_T>0，H_ρ>0，各正弦周期>0，S≥0，消耗率系数非负。显著增大速度、推力或角度时，应重新检查步长及模型适用性。

## 9. 如何继续替换模型

气动替换入口：C的observe_internal和MATLAB的observe；可用自己的C_L、C_D表替换示例系数。

动力替换入口：同一观测函数中的T_cmd与fuel_flow，以及rhs中的T_dot；可以接入经过标定的动力接口。电动动力需另建能量状态和功率映射。

若继续建立六自由度，应另行加入姿态四元数、角速度、力矩、质心与惯量、姿态执行机构等。变质量刚体的角动量方程还取决于惯量变化和流出角动量假设，不能只把固定惯量方程的J换成J(t)就认为模型完整。
